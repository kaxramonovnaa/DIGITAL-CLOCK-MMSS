Digital Clock (MM:SS)
About the Project
This project is a digital clock designed and implemented using digital logic circuits.
It displays minutes and seconds in MM:SS format using four 7-segment displays.
Features
• Four digital counter blocks
• 1 Hz clock signal
• 7-segment displays
• Automatic counter reset
• Carry propagation between counters
Technical Implementation
The project uses:
• Registers
• Adders
• Comparators
• Multiplexers
• AND gates
• Hexadecimal 7-segment displays
Project Structure
• clock_main.dig — Main digital clock circuit
• Digital_Counter.dig — Counter component
• digital.pdf — Project documentation and circuit design
Development
